# Динамические страницы — прототип

Интерактивный прототип работы с компонентами в конструкторе сайтов Saby: виджет из магазина подключает компонент, а компонент приносит на сайт страницы и настройки. Сцена 1600×900 и вспомогательная панель справа.

Проект выделен из прототипа [«Попапы»](https://github.com/IrinaKratyuk/popups): сюда перенесена только часть про компоненты. Окна (режимы «в окне» и «страница и окно», настройки окна, связь кнопки с окном) и внешние виджеты (обратная связь, плавающая кнопка) остались в исходном прототипе.

## Состав

- Рамка демо (шапка, сцена, вспомогательная панель) — компонент `demo-frame` из [ui-kit](https://github.com/MarieSmi/ui-kit), подключён с jsDelivr по тегу `1.13.0`.
- Шапка конструктора — компонент [Builder-components](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=5-28058), узел `5:28058`. Кнопки только с ховером, без действий по клику.
- Правый сайдбар — компонент [Создание страниц и окон](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=148-15451), узел `148:15451`: вписан в страницу, по умолчанию «Магазин»; «Данные»; окно «Параметры сайта».
- Левый сайдбар со списком страниц — компонент [Builder-components](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=5-28393), узел `5:28393`. Режим (вписан или линии) запоминается в браузере, страницы при обновлении возвращаются к исходным.
- Сценарии на вспомогательной панели — состояния сайта, одна группа «Компоненты» (см. раздел «Компоненты» ниже). Прототип открывается на сценарии «Добавление виджета».
- Середина — сайт в конструкторе, [узел `2547:63290`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2547-63290). Ховер виджетов и команды пустого виджета — компонент `widget` из ui-kit. Шрифт сайта Montserrat подключён с Google Fonts.
- Страницы сайта — «Главная»: шапка, баннер, каталог (когда он добавлен), «О нас». Остальные страницы приходят с компонентами.
- Новая страница — «+» в списке страниц открывает окно новой страницы; после сохранения открывается пустая секция под шапкой сайта — [узел `2406:28596`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2406-28596). Кнопка «+ секция» — [узел `4590:7239`](https://www.figma.com/design/rHabzni5OI5D4fxBLQdj2m/?node-id=4590-7239), пока только с ховером.
- Настройки страницы — то же окно, открывается из меню «⋯» страницы. Меню «Доступ» выбирает «Без авторизации» или «Только авторизованным». В SEO кнопка «Описание» раскрывает многострочное поле; доступ и описание сохраняются в странице до перезагрузки прототипа.
- Карточка товара — по клику в магазине (там, где это можно сделать, на виджете стоит точка клика) встаёт в зону контента пустой секции новой страницы вместо пустой ячейки, «Назад» поднимает на уровень секции, [узел `2695:72015`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2695-72015). Из магазина виджет пропадает, удаление возвращает его. Содержимое — рендер макета, выделение и тулбар — `widget` и `toolbar` из ui-kit.
- Виджет «Секция» — всегда один вид: пустое состояние из пяти команд (`siteEmptyContent`) и один набор в тулбаре: «Фон», «Закрепить», «Настройки», «Удалить», «Ещё» (`<template id="sectionCmds">`, вставляется в каждый `[data-section-cmds]`). «Фон» открывает окно «Фон», «Настройки» — настройки секции, у всех секций одинаково (`SEC_NODES`), правка идёт в секцию, из которой открыто окно. «Закрепить» и «Ещё» пока только с ховером.
- Настройки секции — шестерёнка в тулбаре секции открывает [узел `17197:204679`](https://www.figma.com/design/rZBslLyyMuhvoFziHj5SZi/?node-id=17197-204679) в виде `.pe` из ui-kit по левому верхнему углу секции. Название меняется, фон — чипса: пока он не задан, строки нет. Ширина контента, отступы и фон сразу видны на холсте, ✓ сохраняет их в страницу, ✕ и Esc отменяют. В полях отступов — фактические значения секции. В макете есть только ширина «Узкая», «Широкая» и «Во всю ширину» — допущение. «Действие» и «Закрепить снизу» пока без действий.
- Окно «Фон» — перенесено из `interface-prototype` (Figma `16385:63244`): открывается из строки «Фон» настроек секции и по команде «Фон» в тулбаре секции (под командой, зазор 4px). Фон по умолчанию не задан: пустая плашка, HEX пустой, прозрачность 0; фон секции хранится у страницы. HEX и прозрачность, заготовленные цвета и градиенты, картинки (`assets/img/bg/`) и экран «Картинка» с ползунками. Заготовленный цвет или градиент применяется и закрывает окно, картинка оставляет его открытым.
- Перетаскивание — окна настроек (`.pe`: страницы, секции, каталога) двигаются за шапку и не выходят за края сцены, при следующем открытии встают на обычное место. Общий код — `peDraggable`.
- Окна и меню — одновременно открыто только одно: «Параметры сайта», меню «⋯», окно страницы, настройки секции, настройки каталога, окно компонента, окно «Фон». Новое закрывает прежнее, несохранённые правки в нём отменяются. «Фон» из строки настроек встаёт вместо них, правки настроек при этом сохраняются. С родителем остаются только меню, которые без него не работают: «Способ отображения», меню и палитры `PropertyEditor`.
- Свойство «Способ отображения» — строка с меню: разметка в `<template id="openMode">`, стили `.open-mode*`, поведение в `openModeFill`, окно задаёт подпись и список вариантов. Сейчас это «Открывать товар» в настройках каталога. Меню — [узел `2406:20980`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2406-20980).
- Ширина контента — одна на все секции сайта: боковой отступ `--site-gutter` (32), на всю ширину только баннер. Заглушка пустой секции с пятью командами тоже одна: разметка в `<template id="siteEmptyContent">`, стили `.site-empty`, вставляется в каждый `.site-empty`.
- Выделение — при переключении страницы снимается со всех виджетов, на открытой странице оно появляется только кликом. Родитель выделенного виджета получает `.wg--level-2` из ui-kit (`siteParentsSync`, общее правило для секций): только пунктир цветом акцента, при наведении на самого родителя рамка сплошная. Кнопки «+ секция» есть лишь у активной секции.
- Тулбары виджетов при прокрутке остаются поверх шапки конструктора с минимальным отступом 6 px от верха сцены. Координаты тулбара округляются до целых пикселей: иначе при каждом пересчёте текст сдвигается на доли пикселя и «прыгает».
- Футер — [узел `2899:48815`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2899-48815): один шаблон на все страницы. Всегда последний, идёт сразу за последней секцией, ховер зелёный, как у шапки.
- Шрифты Inter, cbuc-icons, cbuc-icons24 и Accordion-Font — в `assets/fonts`, из interface-prototype.

## Компоненты

Виджет из магазина подключает **компонент**: компонент приносит на сайт виджет, страницы и настройки. «Зависит от» — это компоненты, которые приходят вместе с ним и становятся его частью: подключая «Ресторан», подключаем и «Заказы и оплата» (а с ними — «Личный кабинет»). Список и зависимости — из документа «Компоненты интернет магазина» (`COMP` в `app.js`):

|---|---|---|---|---|
| Личный кабинет | — | Вход; Информация о пользователе | Вход и регистрация; Профиль | Способы входа |
| Заказы и оплата | Личный кабинет | Кнопки заказа; Корзина; Оформление заказа; Заказы; Карточка заказа; Статус заказа; Оплата; Сведения о компании; Контакты; Адрес; Режим работы; Выбор региона и точки; Филиалы | Корзина; Заказы; Карточка заказа | Способы оплаты; Правила предоплаты; Получатель платежа; Общие правила оформления заказа; Компания; Доступные точки |

Сведения о компании, Контакты, Адрес, Режим работы, Выбор региона и точки, Филиалы — общие виджеты «Заказов и оплаты» и «Лояльности»: это один набор, он включается с первым из этих компонентов, второй находит его уже включённым. Если отключить один из них, виджеты остаются, пока подключён второй. Так же общие у них настройки «Компания; Доступные точки». По тому же правилу «Куда доставить?», «Выбор доставки или самовывоза» и «Выбор точки и времени получения» — общие виджеты «Магазина» и «Ресторана», как и их настройки «Доставка» и «Самовывоз».

В демке страницы приходят только у «Личного кабинета», «Заказов и оплаты» и «Ресторана», а из настроек работают только точки продаж у «Ресторана». «Доставка» и «Самовывоз» — не компоненты, а две отдельные дополнительные настройки «Магазина» и «Ресторана»: серые чипсы в группе подключённого компонента в «Параметрах сайта», как в блоке «Сайт», пока без действия.

Пример — каталог. В магазине в «Расширенных» четыре каталога (товаров, меню ресторана, услуг, номеров), но работает только «Меню ресторана» (компонент «Ресторан»): у остальных есть ховер, клика нет. В магазине каталоги стоят перед «Карточкой товара».

- Сценарии: «Добавление виджета» — у сайта только «Главная», ни одного компонента; «С компонентами» — «Ресторан» уже подключён, у него две точки продаж.
- Добавление — клик по «Меню ресторана» ставит каталог на «Главную» (между баннером и «О нас»; страница «Меню» не создаётся: виджет уже стоит там, куда его поставили) и подключает «Ресторан» со всей цепочкой зависимостей и их страницами. Если компонент ещё не настроен (нет точек продаж), открывается окно настроек компонента; если настроен — окна нет, виджет берёт его настройки.
- Окно настроек компонента — `.pe` из ui-kit, заголовок — название компонента («Ресторан»). Это то же, что блок компонента в «Параметрах сайта». Сейчас в нём только точки продаж: «+» открывает выбор точек с поиском (если точек ещё нет, отмечены два ресторана «Мили»), ✓ сохраняет, ✕ и Esc отменяют, сброс убирает все точки. Строки перетаскиваются, первая — основная точка, корона у остальных делает точку текущей. Из «Параметров сайта» окно встаёт по центру поверх них. Панель выбора точек продаж соответствует узлу Figma `2596:108384`; графика чекбоксов и кнопки закрытия сохранена в `assets/img/sales-*.svg`.
- Настройки каталога — шестерёнка в тулбаре каталога или клик по уже выделенному виджету (кроме тулбара; двойной клик тоже: первый выделяет, второй открывает) открывает [узел `2547:84587`](https://www.figma.com/design/WHZ4ZSm4wRMrxQPWqEk5Wk/?node-id=2547-84587) в виде `.pe` из ui-kit по левому верхнему углу виджета (если окно не помещается по высоте, оно прижимается к краю сцены); повторный клик, ✓, ✕ и Esc закрывают. Внутри пока только ховер: значения и выбранные плитки — из макета, клики ничего не меняют. Схемы на плитках рисует `CAT_TILES` в `app.js`.
- Демоданные — пока у компонента нет точек продаж, в каталоге вместо фото блюд — демо-фото (`assets/img/site/demo/`), как в превью магазина. С точками — данные точки.
- «Параметры сайта» — «Настройки» в правом тулбаре, макет `2547:76412`. Блок «Сайт»: свойства и подключения к сервисам в SEO — чипсы из ui-kit. В блоке «Добавить компонент» неподключённые компоненты чипсами с иконкой (`assets/img/comp/`) и названием. Клик по чипсе подключает компонент: чипса пропадает, компонент появляется группой со своими настройками (группы идут в том же порядке, что и чипсы); приходят его страницы и неподключённые зависимости со своими страницами. Если виджета компонента на сайте нет, приходит ещё страница «Меню» — первой в группе компонента, с каталогом на ней; каталог пропадает из магазина. Крестик группы отключает компонент: окно подтверждения со списком того, что уйдёт (страницы, в том числе «Меню», и виджет), по «Да» уходят страницы, виджет с сайта и настройки, каталог возвращается в магазин. Зависимости остаются подключёнными. Повторное подключение возвращает страницы на свои места в группе.
- Панель страниц группирует страницы по компонентам: сначала страницы сайта, ниже — группы компонентов (в порядке компонентов) с заголовком из иконки компонента (24 px) и его названия. Заголовок не кликается.
- Страницы создаются под виджет: каждая страница компонента приходит со своим виджетом. «Карточка блюда» — карточка товара, «Меню» — каталог, «Вход и регистрация», «Профиль», «Корзина», «Заказы», «Карточка заказа» — виджет с названием («Профиль покупателя», «История заказов») и демоданными в стиле сайта (`COMP_DEMO` в `app.js`, стили `.pgw-*`): вход по телефону и коду, профиль с баллами и адресами, корзина с двумя позициями, три заказа, состав и статус заказа № 10482. Покупатель и заказы вымышленные, макетов этих виджетов пока нет.
- Страницы компонента принадлежат ему: в меню «⋯» их нельзя сделать главной, скрыть, дублировать и удалить; у основного виджета страницы и его секции нет «Удалить».
- Удаление виджета с «Главной» удаляет только виджет, без вопросов: компонент и его страницы остаются, «Меню» заново не создаётся.
- Окно подтверждения — `.confirm` из interface-prototype (Figma `4064:21938`): по центру сцены поверх всего, Esc — «Отмена».
- Панель «Данные» — переменные «Точки продаж» и «Текущая точка» раскрываются по клику; поля текущей (основной) точки — название, тип справа, значение ниже (Figma `3042:49624`).

Данные точек демонстрационные, из сценария Figma `2547:63896`. Как и страницы прототипа, подключение компонентов и точки продаж живут в текущем сеансе и сбрасываются при перезагрузке.

Пока не делаем: настройки компонентов, кроме точек продаж «Ресторана»; «Отель» с «Рестораном» не прорабатываем.

Логика компонентов описана в концепции: [docs/concept/index.md](docs/concept/index.md#3-компоненты), раздел «Компоненты».

## Запуск

Без сборки и зависимостей:

```bash
node .claude/serve.js
```

Откроется на http://localhost:5173.

## Публикация

Сайт собирается из ветки `main`, папка `/ (root)`. Пуш в `main` обновляет его за 1–2 минуты.
